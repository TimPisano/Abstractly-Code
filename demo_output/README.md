# Phase 6: Maple Ridge end-to-end demo output

Generated by running the live `/loan-underwriting/*` routes against a
local test instance of this branch's backend (feature flag on, seeded
admin, a fresh temp SQLite DB), driven via `curl`.

## Files

- **`Maple_Ridge_Credit_Memo.docx`** — the actual generated credit memo.
  Open this one.
- **`maple_ridge_underwriting_result.json`** — the raw API response
  from `GET /loan-underwriting/requests/4/underwriting`: every number
  in the memo, before rendering.
- **`maple_ridge_t12_input.csv`** — the T-12 operating statement that was
  uploaded to produce this result.

## On the T-12's provenance

`backend/benchmark_data/demo_deal/` (the real `maple_ridge_t12.xlsx`
and the rest of the Maple Ridge fixture package) is **not present on
this branch** — per `TASKS.md`, it lands separately with
`fix/rent-roll-hardening`, and `tests/test_loan_underwriting_demo_deal.py`
already documents this and skips cleanly when the fixture is absent.

So `maple_ridge_t12_input.csv` here is a **CSV reconstruction carrying
the exact same figures**, independently verified byte-for-byte against
the real `maple_ridge_t12.xlsx` earlier in this session (Gross
Potential Rent $2,177,280.00, Vacancy Loss -$107,685.39, Loss to Lease
-$25,521.97, Bad Debt -$122,562.00, Management Fee $59,899.54, NOI
$1,229,888.08 — all matched). It is not claimed to be a byte-identical
copy of the original workbook, only a faithful reconstruction of its
figures in CSV form, built so this phase could run without that
fixture package.

## On the memo's narrative sections

This environment's `ANTHROPIC_API_KEY` has no credit (documented
elsewhere in this project's memory/history), so the real API call the
module attempted for the narrative sections (Property, Rent Roll
Analysis, Risks, Conditions) failed, and the module degraded
gracefully exactly as designed: the memo still rendered completely,
every number intact, with a visible note explaining the narrative
sections weren't generated. **No AI-drafted prose appears in this
particular memo** — only the engine's numbers, tables, and the
permanent recommendation/sponsor placeholders. `tests/test_credit_memo.py`
covers the narrative-generation path itself with a mocked client, so
that logic is tested even though this specific run didn't exercise a
live successful call.

## The recommendation

Section 1 reads **"FOR CREDIT OFFICER DETERMINATION"** — the tool does
not, and will not, recommend approval or denial. See `SUMMARY.md`
("Why the tool won't recommend") for why.
